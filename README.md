# Task Tracker App

The **Task Tracker App** is a full-stack web application that allows users to **create**, **view**, **update**, and **delete** tasks easily.  
It is built with a **React.js** frontend and a **Node.js/Express** backend, offering a smooth and responsive task management experience.

---

## 📚 About the Project

This project demonstrates the complete flow of a **CRUD (Create, Read, Update, Delete)** application with seamless integration between frontend and backend.  
It can serve as a starter project for anyone looking to learn full-stack development or build their own task management solutions.

---

## 🛠️ Tech Stack

**Frontend:**
- React.js
- Vite (for fast development)
- Axios (for API requests)
- TailwindCSS (for styling) 

**Backend:**
- Node.js
- Express.js
- MongoDB 
- CORS and Body-Parser Middleware

---

## 🚀 Features
- Signup
- Login
- Logout
- Create a project(Max 4) 
- Create a task
- Read as Task
- Update a Task
- Delete a Task
- Mark tasks as completed/incomplete
- Responsive and user-friendly UI
- API integration between frontend and backend

## 🔥 How to Run the Project Locally

### 1. Clone the Repository

```bash
git clone https://github.com/vikas9616/Task-Tracker-App.git
cd Task-Tracker-App
```

---

### 2. Run the Backend Server

```bash
cd backend
npm install
npm start
```
- Backend will run on [http://localhost:5000](http://localhost:5000).

---

### 3. Run the Frontend

```bash
cd frontend
npm install
npm run dev
```
- Frontend will run on [http://localhost:5173](http://localhost:5173) (default Vite port).
